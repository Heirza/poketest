# Pokeemerald Expansion - Repositorio de pruebas y aprendizaje 

Este repositorio es un **fork del proyecto [pokeemerald-expansion](https://github.com/rh-hideout/pokeemerald-expansion)** 


Siempre he tenido el sueño de crear mi propia versión de un juego de Pokémon, desde pequeño experimenté con herramientas de RH Tradicional, como Advance Map y XSE para hacer muchas locuras.

Actualmente, siento que conozco las bases sobre programación, y con la aparición de métodos nuevos, como un proyecto Decomp, creo que es momento de concretar mis sueños de la infancia.

Quiero aclarar: 

Dedicaré solo mis tiempos libres a la realización del proyecto, no será algo prioritario, por lo que ver resultados tangibles podría tardar.
